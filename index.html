ik vibecode.

Vibecoden is programmeren door in gewone taal te beschrijven wat je wilt, en de computer het typewerk te laten doen. Jij bepaalt de richting, de machine schrijft de regels code. Deze pagina is daar een voorbeeld van.

Klik op de knop voor een nieuwe vibe.

Nog geen vibes opgehaald.

Hoe vibecoden werkt

  1. Beschrijf wat je wilt Geen syntax, gewoon een zin: "maak een pagina die hallo zegt".
  2. Bekijk wat eruit komt Je krijgt werkende code terug en ziet meteen het resultaat.
  3. Stuur bij "Maak het rustiger", "voeg een knop toe". Kleine stapjes werken het best.
  4. Blijf zelf de baas Jij beoordeelt of het klopt. De computer typt, jij denkt.
Statische pagina, één bestand: index.html. Geen server, geen database, geen installatie.
